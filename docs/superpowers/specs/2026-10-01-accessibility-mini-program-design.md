# 生活服务中心小程序 Demo 设计

## 目标

将当前微信原生 TypeScript 小程序模板扩展为可操作的生活服务中心 Demo，覆盖首页、服务列表、服务详情、设置、个人中心五类页面。主要目标是让微信读屏用户能够理解页面层级、操作名称和控件状态，并能完成页面导航、筛选、收藏和设置等流程。

## 当前项目

项目使用微信原生小程序技术栈：TypeScript、WXML、WXSS。当前注册了欢迎页和日志页，暂无业务数据或共享组件。本次继续使用微信原生页面和组件，采用本地静态数据，不接入后端、账号系统或外部服务。

## 信息架构

- 底部原生 TabBar：`首页`、`服务`、`设置`、`我的`。
- `服务详情`作为普通页面，从首页推荐卡片或服务列表进入；返回操作使用小程序原生导航。
- 各页面按视觉和读屏阅读顺序组织内容，页面标题通过原生导航栏标题和页内标题共同表达。
- 原有日志页不再作为导航入口；首页继续使用当前 `pages/index` 路径，其余页面使用清晰的业务路径。

## 页面设计

### 首页

- 展示欢迎语、带持久文字标签的搜索输入框、服务分类快捷入口、推荐服务和通知入口。
- 搜索后可进入服务列表查看匹配结果。
- 分类快捷入口切换到服务 Tab，并选择对应分类。
- 顶部使用文字和色块构成生活服务主视觉，不承载只有视觉用户才能获取的信息。

### 服务列表

- 提供关键词搜索、分类单选筛选、结果数量和服务卡片。
- 每张卡片显示服务名称、类别和简短说明；整体操作通过原生按钮进入详情。
- 无匹配结果时显示可读的空状态说明和清除筛选操作。
- 搜索与分类筛选使用同一份本地服务数据；结果节点保留在页面内容流中，方便读屏用户按顺序浏览。

### 服务详情

- 展示服务名称、摘要、办理条件、办理步骤、办理时长及联系信息。
- 通过原生复选控件呈现收藏状态；状态写入本地存储，并同步至个人中心收藏列表。
- 联系入口只展示和说明示例操作，不发起真实电话或外部请求。
- 视频为可选内容。只有配置了用户提供的直链后才展示播放器；视频旁提供文字说明或可访问的文字稿，确保关键信息不只存在于视频中。

### 设置

- 提供“大字模式”和“高对比模式”两个原生开关。
- 设置写入本地存储，并作用于其余页面。页面布局避免固定高度裁切放大后的文字。
- 提供简短的无障碍操作说明，提示页面操作顺序与开关效果。
- 首次启动时使用明确的默认设置（常规字号、标准对比度），原因是新安装用户尚无本地偏好；服务数据的必需字段不做兜底。

### 个人中心

- 使用明确标注为 Demo 的本地示例身份，不请求登录或真实个人信息。
- 展示收藏服务、最近浏览和常用入口；列表项可以进入服务详情或切换至对应 Tab。
- 没有收藏或浏览记录时显示有说明文字的空状态。

## 数据与交互

- 使用一个共享的 TypeScript 服务数据模块，服务记录包含稳定 ID、名称、分类、摘要、办理条件、办理步骤、办理时长和联系说明等展示所需字段。
- 搜索按服务名称、分类名称和摘要匹配；分类筛选与关键词搜索可以组合使用。
- 推荐项、搜索结果、收藏和最近浏览均从同一组本地服务记录派生，避免不同页面的展示不一致。
- 收藏与设置使用小程序本地存储；最近浏览在打开详情时更新。
- 可选视频链接不伪造默认值。没有配置链接时不渲染播放器；该字段可选的原因是视频素材需由用户另行提供。
- 页面不从外部加载数据。联系、通知等示范入口通过页面内说明或本地弹窗反馈，不触发外部副作用。

## 无障碍要求

- 优先使用 `button`、`input`、`switch`、`checkbox`、`radio-group` 等原生控件，保留平台原生角色与状态。
- 每个输入项有始终可见的文字标签；占位提示只补充格式或示例，不代替标签。
- 图标不单独承担操作名称。图标与文字重复时隐藏图标节点；有意义的图片提供文字说明。
- 自绘控件在语义缺失时使用小程序支持的 `aria-label`、`aria-role` 等属性；纯装饰节点使用 `aria-hidden` 隐藏。不为原生控件重复叠加可能造成重复播报的名称。
- 收藏、筛选、开关等选择状态同时通过控件状态和可读文字表达，不单靠颜色或图标区分。
- 用分组标题、页内标题和描述文字构建稳定的信息层级；滚动区域按列表语义配置，节点顺序与视觉阅读顺序一致。
- 交互目标采用宽松间距和足够尺寸；正文与背景保持清晰对比，文字支持换行和放大。
- 空状态、操作结果、示例联系方式等均提供有意义的文本，不用仅视觉提示替代。
- 视频若接入，播放器旁提供内容文字说明或文字稿；不依赖自动播放或声音传达唯一信息。

### 页面节点覆盖

| 页面 | 主要读屏节点与状态 |
| --- | --- |
| 首页 | 页内标题、带可见标签的搜索输入框、分类入口按钮、推荐服务按钮、通知说明入口；装饰色块隐藏，标题文字保留。 |
| 服务列表 | 搜索输入框、分类单选组、结果数量文本、清除筛选按钮、服务卡片按钮、无结果说明。 |
| 服务详情 | 服务名称和摘要、办理信息标题与步骤列表、收藏复选控件及勾选状态、联系说明按钮；有视频时增加文字稿入口。 |
| 设置 | 大字模式和高对比模式开关及开关状态、无障碍操作说明。 |
| 个人中心 | Demo 身份文字、收藏和最近浏览分组标题、详情入口、空状态说明、Tab 切换入口。 |

上述节点优先使用原生控件提供名称和状态。页面滚动区域使用 `scroll-view` 的列表语义；动态筛选结果保留为可读文本，不依赖屏幕阅读器对未验证的实时播报行为。

## 视觉方向与资源

- 清爽、克制的生活服务视觉：浅色背景、深色正文、青绿色主色和清晰的卡片分区。
- 页面强调易读性和可触达尺寸，避免信息只靠颜色、图标或图片传达。
- 首页主视觉使用代码绘制的色块与文字，不使用插画；原生 TabBar 使用本地图标资源，并保留“首页/服务/设置/我的”文字标签。
- 首页服务分类和推荐服务均采用双列卡片布局；按钮按边框盒计算尺寸，放大文字时保持内容换行。

## 文件边界

- `miniprogram/app.json`：注册页面和四项原生 TabBar。
- `miniprogram/assets/tabbar/`：四个 Tab 项的常态与选中态 PNG 图标；文字标签继续提供可读名称。
- `miniprogram/app.wxss`：全局颜色、排版及字号/对比主题样式。
- `miniprogram/pages/index/`：生活服务首页。
- `miniprogram/pages/services/`：搜索、筛选及服务列表。
- `miniprogram/pages/detail/`：服务详情与收藏交互。
- `miniprogram/pages/settings/`：无障碍设置。
- `miniprogram/pages/profile/`：个人中心。
- `miniprogram/data/services.ts`：有类型约束的本地服务示例数据。
- 首页主视觉使用 WXSS 色块构成，无插画资源。
- TypeScript 中的函数、变量及复杂业务逻辑添加简体中文注释。

## 验收标准

1. 微信开发者工具能够编译并进入首页；四个 Tab 页面可互相切换，详情可进入和返回。
2. 首页搜索与分类快捷入口、列表关键词/分类筛选、详情收藏、设置开关、个人中心记录均可按预期操作。
3. 设置、收藏和最近浏览在页面切换后仍正确展示；首次启动有明确的字号和对比度默认值。
4. 主要交互使用原生控件或带有小程序无障碍语义的自绘节点；输入、状态、图片、空状态和导航均有合适的文字表达。
5. 大字和高对比设置作用于所有页面，文字能够换行，不因固定高度被裁切。
6. TypeScript 检查通过。读屏节点与页面层级可在微信开发者工具中逐页检查；屏幕阅读器的实际播报效果仍需真机验证。

## 范围外

- 服务端、登录、真实个人资料、支付和真实联系操作。
- 需要用户提供直链的视频资源；视频结构按可选内容设计。
- 为可访问性承诺特定屏幕阅读器播报细节。开发者工具检查和真机读屏测试分开记录。

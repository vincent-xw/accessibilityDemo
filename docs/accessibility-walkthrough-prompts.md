# 小程序无障碍走查短录制 Prompt

本文将走查拆成独立短片段。每段只验证一个页面或一组紧密相关的交互，可单独发送对应 Prompt 执行和录制。每条 Prompt 已写明要使用的工具，不需要另发总览。

建议每段录制约 20–60 秒，只保留该场景的操作和关键节点证据。遇到明显问题时记录后继续，不要在一段视频里临时展开全站排查。

## Prompt 1：首页入口

**主要验证功能：** 页面主标题、搜索输入与搜索按钮、分类入口卡、推荐服务卡、底部 Tab 名称及当前选中状态。

```text
工具要求：无障碍节点使用 Snapshot Companion（mobile_snapshot_companion）；只有进行像素级视觉对比时才使用 Screen Analyze。不要修改代码或推断未观测到的结果。

先确认当前页面是否为首页，主标题应为“社区生活服务”。如果不是，点击底部“首页”Tab；若当前子页面没有底部 Tab，先逐级返回到带底部 Tab 的页面再切换。确认标题后再开始分析，不要把当前页面直接当成首页。读取主标题、搜索框和搜索按钮的名称与角色；抽查一个分类卡和一个推荐服务卡，确认名称能说明操作目标。查看底部 Tab 是否以中文呈现，并确认“首页”为当前选中项。最后执行一次搜索，记录搜索后的页面或结果反馈是否可发现。用简体中文记录结论、操作步骤和节点证据；无法确认的播报表现标为“未验证”。
```

```text
工具要求：无障碍节点使用 Snapshot Companion（mobile_snapshot_companion）；只有进行像素级视觉对比时才使用 Screen Analyze。不要修改代码或推断未观测到的结果。

先确认当前页面是否为服务列表，主标题应为“生活服务”。如果不是，点击底部“服务”Tab；若当前子页面没有底部 Tab，先逐级返回到带底部 Tab 的页面再切换。确认标题后再开始分析，不要把当前页面直接当成服务列表。核对搜索框名称和帮助说明、类别单选组及选中状态、结果列表和结果数量。切换一个类别，再搜索一个关键词，确认筛选状态与结果数量同步更新；如果方便，再制造一次无结果状态，检查提示和清除入口。检查底部“服务”Tab 的选中状态。用简体中文记录结论、操作步骤和节点证据；无法确认的播报表现标为“未验证”。
```

## Prompt 3：普通服务详情

**主要验证功能：** 标题层级、办理条件和步骤列表、收藏控件状态、联系说明按钮。

```text
工具要求：无障碍节点使用 Snapshot Companion（mobile_snapshot_companion）；只有进行像素级视觉对比时才使用 Screen Analyze。不要修改代码或推断未观测到的结果。

先确认当前页面是否为“社保卡服务”详情，主标题应为“社保卡服务”。如果不是，返回到带底部 Tab 的页面，点击“服务”；在列表中搜索“社保卡服务”，再点对应结果卡片。确认主标题后再开始分析；若找不到该服务，报告“未验证”，不要分析其他详情页。检查页面标题层级、办理条件和步骤的列表项名称及顺序、收藏复选框的中文名称和选中状态、联系说明按钮名称。切换一次收藏状态，确认状态可感知，然后恢复进入页面前的状态。用简体中文记录结论、操作步骤和节点证据；无法确认的播报表现标为“未验证”。
```

## Prompt 4：社区活动详情与图片

**主要验证功能：** 活动图片中文替代说明和可见图注、视频待提供说明、报名入口按钮。

```text

先确认当前页面是否为“社区活动报名”详情，主标题应为“社区活动报名”。如果不是，返回到带底部 Tab 的页面，点击“服务”；在列表中搜索“社区活动报名”，再点对应结果卡片。确认主标题后再开始分析；若找不到该服务，报告“未验证”，不要分析其他详情页。检查活动图片是否作为一个有中文替代说明的图片节点出现，附近是否有可见图注；检查视频待提供区域是否只是说明文字；检查报名入口按钮名称。点击报名入口进入表单，并记录实际到达页面。用简体中文记录结论、操作步骤和节点证据；无法确认的播报表现标为“未验证”。
```

## Prompt 5：表单字段与选择控件

**主要验证功能：** 字段标签、帮助文字、必填/可选状态、日期选择器、单选组、复选组和备注输入框。

```text
工具要求：无障碍节点使用 Snapshot Companion（mobile_snapshot_companion）；只有进行像素级视觉对比时才使用 Screen Analyze。不要修改代码或推断未观测到的结果。

先确认当前页面主标题为“社区活动报名演示”。如果不是，返回到带底部 Tab 的页面，点击“服务”；搜索并打开“社区活动报名”，再点击“填写活动报名演示”。确认表单标题后再开始分析；若无法到达该表单，报告“未验证”，不要把其他页面当成表单。逐项检查联系人称呼、活动日期、活动场次、无障碍协助和备注。确认每个控件能关联到中文标签和帮助文字，必填或可选状态清楚；打开日期选择器，切换一个场次，并勾选一个协助选项，核对状态是否同步。此段不提交表单。用简体中文记录结论、操作步骤和节点证据；无法确认的播报表现标为“未验证”。
```

## Prompt 6：表单必填错误

**主要验证功能：** 必填校验、字段错误关联、错误摘要动态提示。

```text
工具要求：无障碍节点使用 Snapshot Companion（mobile_snapshot_companion）；只有进行像素级视觉对比时才使用 Screen Analyze。不要修改代码或推断未观测到的结果。

先重新进入一个全新的空白报名表单：返回到带底部 Tab 的页面，点击“服务”，搜索并打开“社区活动报名”，再点击“填写活动报名演示”。确认主标题为“社区活动报名演示”且必填字段为空后再分析；若无法确认，报告“未验证”。提交空表单，检查联系人、日期、场次对应的错误文字是否出现，字段是否标记为无效，错误摘要是否出现并说明需要补充的项目。确认错误信息能从对应字段发现；记录实际状态，不推断屏幕阅读器一定会自动跳转或播报。用简体中文记录结论、操作步骤和节点证据；无法确认的播报表现标为“未验证”。
```

**主要验证功能：** 有效表单提交、成功动态提示及信息未保存说明。

```text

先重新进入一个全新的报名表单：返回到带底部 Tab 的页面，点击“服务”，搜索并打开“社区活动报名”，再点击“填写活动报名演示”。确认主标题为“社区活动报名演示”后再分析；若无法确认，报告“未验证”。填写联系人称呼，选择活动日期和一个活动场次后提交报名演示。检查成功提示是否出现、是否说明信息未发送或保存，以及该提示是否具有动态播报语义。无需填写可选协助和备注。用简体中文记录结论、操作步骤和节点证据；无法确认的播报表现标为“未验证”。
```

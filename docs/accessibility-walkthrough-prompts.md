# 小程序无障碍走查短录制 Prompt

本文将走查拆成独立短片段。每段只验证一个页面或一组紧密相关的交互，可单独发送对应 Prompt 执行和录制。每条 Prompt 已写明要使用的工具，不需要另发总览。

建议每段录制约 20–60 秒，只保留该场景的操作和关键节点证据。遇到明显问题时记录后继续，不要在一段视频里临时展开全站排查。

# 小程序无障碍走查短录制 Prompt

本文将走查拆成独立短片段。每段只验证一个页面或一组紧密相关的交互，可分开交给 Agent 执行和录制；不要求一次录完整个小程序。

## 通用要求

每次执行时，把本节要求和对应场景的 Prompt 一起发送：

```text
使用 Companion Snapshot（mobile_snapshot_companion）检查小程序的实际无障碍语义树，并按场景完成指定操作。不要修改代码。只记录实际看到的节点、名称、角色、状态和关系；无法从快照确认的读屏表现请标记“未验证”，不要推断。所有用户可听到的名称和说明应为简体中文。完成后按“通过 / 问题 / 未验证”给出结论，并附上页面、操作步骤和节点证据。
```

建议每段录制约 20–60 秒，只保留该场景的操作和关键节点证据。遇到明显问题时记录后继续，不要在一段视频里临时展开全站排查。

## Prompt 1：首页入口

**主要验证功能：** 页面主标题、搜索输入与搜索按钮、分类入口卡、推荐服务卡、底部 Tab 名称及当前选中状态。

```text
检查首页。读取主标题、搜索框和搜索按钮的名称与角色；抽查一个分类卡和一个推荐服务卡，确认名称能说明操作目标。查看底部 Tab 是否以中文呈现，并确认“首页”为当前选中项。最后执行一次搜索，记录搜索后的页面或结果反馈是否可发现。
```

## Prompt 2：服务列表与筛选

**主要验证功能：** 搜索帮助信息、类别单选状态、结果数量动态反馈、服务结果列表及空结果提示。

```text
检查服务列表页。核对搜索框名称和帮助说明、类别单选组及选中状态、结果列表和结果数量。切换一个类别，再搜索一个关键词，确认筛选状态与结果数量同步更新；如果方便，再制造一次无结果状态，检查提示和清除入口。检查底部“服务”Tab 的选中状态。
```

## Prompt 3：普通服务详情

**主要验证功能：** 标题层级、办理条件和步骤列表、收藏控件状态、联系说明按钮。

```text
从列表打开“社保卡服务”详情。检查页面标题层级、办理条件和步骤的列表项名称及顺序、收藏复选框的中文名称和选中状态、联系说明按钮名称。切换一次收藏状态，确认状态可感知，然后恢复进入页面前的状态。
```

## Prompt 4：社区活动详情与图片

**主要验证功能：** 活动图片中文替代说明和可见图注、视频待提供说明、报名入口按钮。

```text
从列表打开“社区活动报名”详情。检查活动图片是否作为一个有中文替代说明的图片节点出现，附近是否有可见图注；检查视频待提供区域是否只是说明文字；检查报名入口按钮名称。点击报名入口进入表单，并记录实际到达页面。
```

## Prompt 5：表单字段与选择控件

**主要验证功能：** 字段标签、帮助文字、必填/可选状态、日期选择器、单选组、复选组和备注输入框。

```text
在社区活动报名页逐项检查联系人称呼、活动日期、活动场次、无障碍协助和备注。确认每个控件能关联到中文标签和帮助文字，必填或可选状态清楚；打开日期选择器，切换一个场次，并勾选一个协助选项，核对状态是否同步。此段不提交表单。
```

## Prompt 6：表单必填错误

**主要验证功能：** 必填校验、字段错误关联、错误摘要动态提示。

```text
在报名页保持必填项为空并提交。检查联系人、日期、场次对应的错误文字是否出现，字段是否标记为无效，错误摘要是否出现并说明需要补充的项目。确认错误信息能从对应字段发现；记录实际状态，不推断屏幕阅读器一定会自动跳转或播报。
```

## Prompt 7：表单成功状态

**主要验证功能：** 有效表单提交、成功动态提示及信息未保存说明。

```text
填写联系人称呼，选择活动日期和一个活动场次后提交报名演示。检查成功提示是否出现、是否说明信息未发送或保存，以及该提示是否具有动态播报语义。无需填写可选协助和备注。
```

## Prompt 8：无障碍设置

**主要验证功能：** 大字模式和高对比模式的名称、说明、开关状态同步及页面样式变化。

```text
检查无障碍设置页的“大字模式”和“高对比模式”。核对开关名称、用途说明和当前状态；分别切换一次，观察开关状态及页面显示是否同步变化，随后恢复进入页面前的状态。检查底部“设置”Tab 的选中状态。
```

## Prompt 9：个人中心

**主要验证功能：** 常用功能入口、收藏列表、最近浏览列表及空状态。

```text
检查“我的”页面。核对主标题、常用功能入口、我的收藏和最近浏览区域。若列表有内容，抽查一项的中文名称、列表位置和打开详情操作；若列表为空，检查空状态说明是否清楚。检查底部“我的”Tab 的选中状态。
```

## 每段结果记录格式

```text
场景：
实际操作：
检查结果：通过 / 问题 / 未验证
节点证据：角色、中文名称、状态或节点标识
问题与建议：
```

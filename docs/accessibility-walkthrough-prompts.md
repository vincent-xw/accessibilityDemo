# 小程序无障碍走查短录制 Prompt

本文将走查拆成独立短片段。每段只验证一个页面或一组紧密相关的交互，可单独发送对应 Prompt 执行和录制。每条 Prompt 已写明要使用的工具，不需要另发总览。

建议每段录制约 20–60 秒，只保留该场景的操作和关键节点证据。遇到明显问题时记录后继续，不要在一段视频里临时展开全站排查。

## Prompt 1：首页入口与服务列表

**主要验证功能：** 首页标题与搜索控件、分类卡片名称和跨 Tab 跳转、服务列表筛选状态、搜索结果及结果数量。

```text
工具要求：无障碍节点使用 Snapshot Companion（mobile_snapshot_companion）；只有进行像素级视觉对比时才使用 Screen Analyze。不要推断未观测到的结果。

先确认当前页面是否为首页，主标题应为“社区生活服务”。如果不是，点击底部“首页”Tab；若当前子页面没有底部 Tab，先逐级返回到带底部 Tab 的页面再切换。确认标题后再开始分析。检查搜索框、搜索按钮和“办事服务”分类卡的中文名称；点击分类卡，确认页面切换到“服务”Tab，并核对目标页标题“生活服务”、Tab 选中状态、类别选中状态和结果数量。然后在列表中搜索“社保卡”，检查结果卡名称和结果数量；如录制时间允许，再搜索一个不存在的服务词，检查空结果提示。用简体中文记录结论、操作步骤和节点证据；无法确认的播报表现标为“未验证”。
```
